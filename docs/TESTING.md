# الاختبارات – Testing

## الاختبارات الآلية (78 اختبارًا، كلها ناجحة)
```bash
dotnet test --project tests/Mawaqeety.Tests/Mawaqeety.Tests.csproj
```
| المتطلب | الاختبار الآلي |
|---|---|
| 1. صحة المواقيت | مقارنة مع مكتبة astral المستقلة (7 مدن × 6 تواريخ، ≤ 90 ثانية)، وتحقق من ظل العصر للمذهبين، وأم القرى في رمضان، وكل طرق الحساب × كل المدن (ترتيب صحيح)، وخطوط العرض العليا. |
| 2. دقة العد التنازلي | `Status_reports_next_prayer_and_progress` و`Pre_alert_fires_before_prayer_and_next_wake_is_accurate` (الاستيقاظ في الثانية الصحيحة). |
| 3. وصول الإشعارات في موعدها | `Fires_at_prayer_time_...`، و`Pre_alert_...`، و`Wake_from_sleep_within_grace...`. |
| 5. الاستمرار بعد إغلاق النافذة | المجدول مستقل عن النافذة (يعمل على thread pool). يُتحقق منه يدويًا. |
| 6. العمل دون إنترنت | المحرك المحلي هو الأساس، و`Online_cache_is_used_only_when_plausible`. |
| 7. تغيير المدينة | `Times_fall_on_the_requested_local_date...`، و`All_catalog_time_zones_resolve`، والبحث العربي والإنجليزي. |
| 8. تغيير التاريخ | `Crossing_midnight_schedules_tomorrows_fajr`. |
| 9. التوقيت الصيفي | `Daylight_saving_shifts_local_clock_not_the_sun` (القاهرة)، و`London_has_no_dst_bugs_on_transition_day`، و`Manual_offset_with_dst_adds_an_hour`. |
| 10. منع التكرار | `Fires_..._exactly_once_even_across_restarts`، و`Paused_alerts_are_suppressed_and_not_replayed`. |

## قائمة الاختبار اليدوي على Windows 10 و11 (قبل كل إصدار)
| # | الخطوات | النتيجة المتوقعة |
|---|---|---|
| M1 | ثبّت Setup.exe على جهاز نظيف | اختصار على سطح المكتب وفي Start، والبرنامج يفتح، ويظهر في "التطبيقات المثبتة". |
| M2 | الإعدادات ← إرسال إشعار تجريبي | يظهر Toast بالعربية مع زر "إيقاف الصوت" ويُسمع الصوت. |
| M3 | اضبط تعديل الدقائق ليصبح أقرب وقت بعد دقيقتين | يصل الإشعار في الدقيقة الصحيحة، مرة واحدة. |
| M4 | أغلق النافذة (X) وانتظر التنبيه التالي | البرنامج يبقى في شريط المهام ويصل التنبيه. |
| M5 | أعد تشغيل الكمبيوتر | يبدأ البرنامج في الخلفية تلقائيًا (أيقونة فقط) وتستمر التنبيهات. |
| M6 | افصل الإنترنت وأعد تشغيل البرنامج | المواقيت تظهر طبيعيًا، والبحث العالمي يعرض "لا توجد نتائج" دون أخطاء. |
| M7 | غيّر المدينة إلى مكة ثم إلى لندن | تتغير المواقيت والمنطقة الزمنية وطريقة الحساب المقترحة. |
| M8 | غيّر تاريخ Windows يدويًا إلى الغد | تتحدث اللوحة والجدول فورًا (حدث TimeChanged). |
| M9 | غيّر المنطقة الزمنية في Windows، أو اختبر تاريخًا قبل وبعد تغيير الساعة | الأوقات صحيحة بالتوقيت المحلي. |
| M10 | شغّل البرنامج مرتين | لا تُفتح نسخة ثانية، والنافذة الحالية تظهر في المقدمة. |
| M11 | من قائمة شريط المهام: إيقاف مؤقت 30 دقيقة | لا تنبيهات خلال المدة، ولا تُعاد التنبيهات الفائتة بعدها. |
| M12 | التقويم الشهري ← تصدير Excel وPDF | ملفات عربية RTL صحيحة، واليوم الحالي مميز. |
| M13 | إلغاء التثبيت من الإعدادات | يُزال البرنامج والاختصارات ومفتاح التشغيل التلقائي. |
| M14 | مدير المهام بعد ساعة من العمل في الخلفية | ذاكرة أقل من ~120MB، ومعالج ~0% في الخمول. |
