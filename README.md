# Mushaf pages (Madinah Mushaf, Hafs)

604 page images of the Madinah Mushaf printed by the King Fahd Glorious Qur'an Printing Complex,
used by the Mawaqeety app's page-by-page Mushaf view.

Source images: https://github.com/GovarJabbar/Quran-PNG — downscaled here to 1440 px wide,
4-level grayscale, to keep the full download around 66 MB.
